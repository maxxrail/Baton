# Cancelling or changing an order

## Cancelling

You can cancel an order while it's still processing, before it ships. Cancelling refunds the
full amount to the original payment method. Once an order has shipped it can't be cancelled;
you can return it after it arrives instead.

## Changing the shipping address

The shipping address can be changed while the order is still processing. New addresses must be
in the US. Once an order has shipped, the carrier controls it and we can't redirect it.

## Adding or removing items

We can't add items to an order that has already been placed. Place a second order for the
extra items, or cancel the first order while it's processing and order again.
