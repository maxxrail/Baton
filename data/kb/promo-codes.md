# Promo codes and discounts

## One code per order

You can use one promo code per order. Codes can't be combined with each other or with
subscriber pricing.

## Code not working?

Check the expiry date and minimum spend in the email the code came in. Codes are
case-insensitive. Some codes exclude sale items, gift cards and cast-iron sets.

## Forgot to use a code

Codes can't be added after an order is placed. If the order is still processing, you can
cancel it and order again with the code.

## Newsletter welcome code

Sign up for our newsletter to get 10% off your first order. The code is emailed right away and
is valid for 30 days.
