# Exchanging an item for a different size or colour

## How exchanges work

We don't do direct swaps. To exchange an item, return it for a refund within the 30-day return
window and place a new order for the size or colour you want. That way the new item ships
right away instead of waiting for the return to arrive.

## Exchange shipping

When you exchange for a different size or colour of the same product, we waive the $6.95
return shipping fee. Contact support and mention it's an exchange when you start the return.

## Defective items

If the item arrived damaged or doesn't work, see "Damaged, defective or wrong items": we send a
replacement at no cost.
